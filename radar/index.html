Observed radar, not a forecast. The Pi retains compact categorical grids extracted from the official precipitation colours, not PNGs or inferred rain-rate values. The grid is registered from the product's 100 km range geometry onto the same Web-Mercator Malta frame as the satellite panel. Clean display smooths the palette, suppresses isolated specks and hides only high-confidence radial-sector/range-ring clutter found in the official source. Satellite-lightning rings are locally derived approximate activity-area centres from EUMETSAT's five-minute LI AFA display coverage; they are not ground strikes or exact flash locations. A licensed point feed, if configured later, remains distinct. Neither mode changes a retained radar grid or interpolates motion.

Inspect or replace the local data-grid list

The Pi stores compact MRG1 categorical data grids (0 = no echo; 1–14 = exact official palette classes), never source PNGs. Newer scans can include a separate MRD1 source-edge display mask; it only improves contours on screen and never changes the stored grid. Clean display applies screen-only quality control to obvious low-intensity radial fans and near-radar range rings; Full source lets you inspect every retained source-derived value. A separate local strikes.json manifest holds marker records only. By default these are locally derived satellite lightning-activity areas from the public EUMETSAT LI AFA display coverage, never claimed as individual strikes. A licensed numerical point feed may replace them. The marker layer is time-matched to each radar frame and never makes a third-party browser request. The viewer normally reads the Pi manifest. Its ten-minute collector inspects two likely current public image products in memory, keeps a grid only when rain is present, then discards the image. The representation is derived from the rendered official product, not a public ODIM/rain-rate volume.
